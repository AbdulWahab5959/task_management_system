## Failed Attempt and Rerun

The first `npm.cmd run lint` after the My Tasks change failed with one error:

- `MyTasksPage.tsx:55` - `react-hooks/set-state-in-effect`: calling `setState` synchronously inside an effect body.

The cause was the new project-list effect resetting state on a null tenant. The effect was rewritten to defer the reset through `queueMicrotask` with an `active` guard, matching the pattern already used elsewhere in the app. The immediately following lint rerun passed with no problems. This failed attempt is recorded rather than hidden; the code now reflects the fixed version only.
